# IPF_BAL_paper
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21277000.svg)](https://doi.org/10.5281/zenodo.21277000)

This repository contains the R scripts and analysis workflows used in the study:

> *Type I interferon–activated myeloid states are associated with less fibrotic stages in idiopathic pulmonary fibrosis*

## Contents

- scRNA-seq analysis
- Xenium spatial transcriptomics analysis
- Figure generation scripts
- Supporting analysis workflows

## Requirements

- R (version 4.3.0)
- Seurat
- Other required R packages
